# Iris Flower Classification Using Machine Learning

## Project Overview
This project uses Machine Learning to classify Iris flowers into different species using the Decision Tree Classification algorithm.

The model is trained using the famous Iris dataset from Scikit-learn.

The project demonstrates:
- Data loading
- Data splitting
- Model training
- Prediction
- Accuracy evaluation

---

## Technologies Used
- Python
- Scikit-learn

---

## Machine Learning Algorithm
- Decision Tree Classifier

---

## Dataset Used
The Iris dataset contains:
- Sepal length
- Sepal width
- Petal length
- Petal width

Target classes:
- Setosa
- Versicolor
- Virginica
